# 剪气口增强方案（R100）

> 状态：已确认待实施（2026-09-18）
> 范围：工具箱 → 剪气口

## 1. 目标

剪气口目前是"黑盒批量"：调参数 → 跑 → 看结果，无法预判剪了什么。本方案增加**可视化预览 + 精细化参数**，让用户"看得见剪了什么"再决定是否正式跑。

## 2. 交互流程

1. 剪气口页（单文件模式）旁新增 **「预览检测」** 按钮
2. 点击后对当前选中文件分析：后端跑一次 VAD 推理，返回波形 + 概率序列
3. 前端弹层展示**波形预览面板**（不落地任何文件）
4. 用户拖动参数 → **前端本地重算**切分点（零延迟，不重复推理）
5. 满意后关闭面板，批量/单文件模式沿用当前参数正式跑

## 3. 参数（由 3 项 → 5 项）

| 参数 | 说明 | 默认 | 范围 |
|---|---|---|---|
| 灵敏度 sensitivity | VAD 说话概率阈值，越低越敏感 | 0.5 | 0.2~0.9 |
| 最小静音 min_silence | 静音达到此时长才剪 | 0.6s | 0.1~10 |
| 前垫片 pad_before | 剪切点前保留的留白 | 0.3s | 0~3 |
| 后垫片 pad_after | 剪切点后保留的留白 | 0.3s | 0~3 |
| 最长静音上限 max_silence | 静音超过此时长视为**有意停顿，不剪**（防误剪长停顿） | 5s | 1~30 |

**切分规则**：静音间隔 < min_silence 合并为同段；min_silence ≤ 间隔 ≤ max_silence 作为切分点；间隔 > max_silence 视为有意停顿（合并保留）。

## 4. 预览面板内容

- **波形标注**：音频波形（降采样 ~600 点）+ 静音段色块 + 剪切线 + 时间轴；被剪部分灰显
- **统计卡**：原时长 / 剪后时长 / 剪掉 X 段共 Y 秒 / 保留率 %
- **试听**：手动点按
  - 试听原片：第一处剪点附近片段（约 4s）
  - 试听剪后：前 3 个保留段拼接（约 6s）

## 5. 技术方案

### 后端（toolbox/vad_cut.py + web_app.py）

- 新增 `analyze_pauses(video_path, params)`：
  1. 提取 16k wav（复用现有 `_extract_wav`）
  2. VAD 逐帧推理一次，得到概率序列 `probs`（每 512 样本/32ms 一点）
  3. 计算波形降采样点 `waveform`（min-max 包络 ~600 点，画波形用）
  4. 返回 `{dur, probs, waveform, sr}`——**不含切分点**，切分交给前端本地重算
- `cut_pauses` / `cut_batch` 参数改为 5 项（`keep_pad` 拆成 `pad_before`/`pad_after`，新增 `max_silence`），切分规则同上
- 新增 `/api/toolbox/vad/preview`（POST）：返回分析数据
- 新增 `/api/toolbox/vad/preview_audio`（GET）：`mode=orig|cut` + `file`，ffmpeg 生成 4~6s 试听 mp3 流返回

### 前端（剪气口页）

- 参数区改 5 项（滑块 + 数值显示）
- 「预览检测」按钮 → 弹层：
  - `<canvas>` 绘制波形（波形填充 + 静音段底色 + 剪切线 + 时间刻度）
  - 统计卡 DOM
  - 试听按钮 ×2（`<audio>` 元素，点按加载后端音频流）
- 滑块拖动（防抖 150ms）→ 本地重算切分：阈值滞后切分 → 合并 → pad → max_silence 过滤 → 重绘
- 切分逻辑与后端保持一致（同规则实现，避免预览与正式结果不一致）

### 兼容性

- 旧参数 keep_pad 不再使用；接口入参改为 pad_before/pad_after/max_silence
- 已保存的配置若含 keep_pad：忽略，使用默认 pad 0.3/0.3
- 批量模式沿用同一套 5 参数

## 6. 验证清单

- [ ] 预览接口：单文件返回 probs/waveform/dur，无音频文件报错
- [ ] 前端切分重算与后端正式剪切分一致（同一文件对比剪点）
- [ ] 参数拖动 → 剪切线实时更新，无重复 VAD 推理
- [ ] 试听接口：orig/cut 均返回可播放音频
- [ ] 正式剪使用 5 参数，结果与预览一致
- [ ] max_silence 生效：长停顿不被剪
