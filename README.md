# 信息流素材一键拼接

本地运行的**批量短视频成片工作台**：把「开头素材 + 任意数量中间素材 + 结尾素材」批量组合、差异化处理并导出成片，专为信息流/短视频多平台投放设计。无需上传任何素材，全部在本地完成。

---

## 一、快速开始

### 方式 A：便携版（推荐，其他电脑可直接用）

1. 解压 `信息流素材一键拼接-便携版-版本号.zip`
2. 双击文件夹内的 `信息流素材一键拼接.exe`
3. 自动打开浏览器进入工作台（地址 `http://127.0.0.1:8765`），无需安装 Python / FFmpeg

> 首次启动约需 3~5 秒；**关闭浏览器不会退出程序**（后台服务继续运行），需要停止时点击界面左下角「退出程序」按钮。

### 方式 B：开发版（本机源码运行）

```
pip install -r requirements.txt
python web_app.py
```

浏览器打开 `http://127.0.0.1:8765`。

左侧导航四步，按顺序完成：

```
1 素材库  →  2 参数配置  →  3 去重  →  4 生成与结果
```

## 三、第一步：素材库

| 区域 | 作用 |
|---|---|
| **开头素材库** | 选择片头视频文件夹；点击卡片可**固定某条为片头**（蓝框 + 顶部"已固定开头"提示） |
| **结尾素材库** | 选择片尾视频文件夹；同样可固定片尾 |
| **中间素材池（可添加多个）** | 选择中间视频文件夹；可**添加多个池**（最多 5 个），按池顺序插入头尾之间；展开后可勾选指定素材或由程序随机抽取 |
| **背景音乐（可选）** | 选择音乐文件夹（MP3/WAV/M4A/FLAC/OGG），支持**固定**或**随机**配乐 |
| **输出目录（必填）** | 成片保存位置；未填写时左侧「素材库」步骤标红，点击「开始生成」会被拦截 |

**素材规则**
- 素材库区域每个板块限制**两排显示**，超出后在该板块内滚动查看，不撑乱页面
- 素材全部在本地扫描，不复制、不移动你的原文件
- 点击素材卡片 = 固定；再次点击 = 取消固定
- 每张素材卡片带**音量滑块**（0~2 倍），可单独调整该素材音量，双击滑块恢复默认 1.00

## 四、第二步：参数配置

| 参数 | 说明 |
|---|---|
| **出片数量** | 期望生成条数（1~200）。下方快捷档位 10/20/50/100/200 一键直达；**智能感知素材上限**——超过素材可组合上限的档位会变灰并提示"素材最多可拼 N 条" |
| **并发任务数** | 同时生成的路数（1~8），显卡加速建议 2~4，CPU 建议 1~2 |
| **分辨率** | 预设：抖音竖屏 1080×1920 / 快手竖屏 / 小红书竖屏 / B站横屏 / 信息流 15s / 25s / 30s，或自定义 |
| **目标时长** | 不限制 / 15s / 25s / 30s 等 |
| **编码加速** | 自动检测 / 显卡加速（NVENC，速度快）/ 仅 CPU |
| **随机转场** | 默认**不使用**；可选固定转场或随机转场，均可自定义转场时长，随机模式从多种转场效果中抽取 |
| **背景音乐** | 默认**不使用**；开启后可选音乐文件夹随机/固定、BGM 音量、淡入淡出 |
| **统一音量** | 对成片做响度归一化，避免各素材音量忽大忽小 |
| **水印** | 勾选后选择水印图片，支持铺满全屏 / 右下角 / 左上角等位置 |
| **自动字幕** | 可选（需额外安装 faster-whisper） |
| **文件名模板** | 自定义输出文件名，支持 `{序号}` `{开头}` `{结尾}` 等变量，如 `output_{序号}_{开头}_{结尾}` |
| **随机种子** | 控制组合随机顺序，固定种子可复现同一批结果；点「随机」按钮可一键刷新 |
| **参数模板** | 可将当前全部配置保存为模板，下次一键载入 |

> 生成过程中修改参数不会影响当前任务（任务参数已锁定快照），只会在下次任务生效，并有提示。

## 五、第三步：去重差异化

应对平台「内容指纹判重」：同批成片若画面/音频/结构高度一致，容易被判重复视频。

| 强度 | 效果 | 适用 |
|---|---|---|
| **关闭** | 不做差异化，每条成片内容一致 | 单条投放 |
| **轻度** | 画面与音频轻微扰动，观感基本不变 | 少量降重 |
| **深度** | 片段级差异化：入点偏移、素材顺序、转场随机、插帧、镜像、噪点、变速等组合 | 大批量投放防判重 |

**差异化维度（深度模式下随机组合）**
- 画面微调：亮度/对比度/饱和度 ±5-10%、随机裁切缩放
- 片段差异化：随机入点偏移、素材顺序、插帧、随机转场
- 音频差异化：BGM 随机起播位置、轻微变速
- 变速调整：整体速度 ±1-3%（音画同步、观感无感）
- 水平镜像、轻噪点叠加等

**去重版本数**：开启去重后，每条成片可生成多个差异化版本（1~5 版），版本间参数不同、互不重复。

## 六、第四步：生成与结果

### 开始前体检（自动）

进入本页自动预检，面板显示：

```
基础成片   所选素材最多可拼接的条数（组合上限）
预期生成   你选择的出片数量
实际生成   最终将生成的成片数量
预计生成时间   按历史实测速度估算
```

- 逐项检查：素材可读性、输出目录、磁盘空间、生成数量、FFmpeg 引擎、固定素材状态
- 未选择素材路径/输出目录会逐项红色提示，不会整体报错无说明
- 每项提示悬停可查看原因；「重新体检」随时刷新

> 三个数量的关系：基础成片 ≥ 预期生成 ≥ 实际生成。素材组合不足时按可用组合出片（不重复出片），实际生成 = 最终结果条数。

### 生成控制

| 按钮 | 作用 |
|---|---|
| **开始生成** | 按当前参数批量生成（必填项缺失会拦截并标红） |
| **试片（1条）** | 只生成 1 条用于查看效果（可拖动进度条），不写入任务历史，预览文件只保留最近 5 个 |
| **继续** | 断点续跑：上次中断/取消的任务，已完成的自动跳过继续生成 |
| **取消** | 停止当前任务；已生成的不受影响，未完成条数单独显示 |
| **重试失败项** | 只重试失败的那些成片 |

### 任务队列

- 可把多批配置加入队列（命名如"A组-横屏-15s"），当前任务完成后自动依次执行
- 重启程序后队列清空

### 结果与历史

- **生成结果**：最多 5 条/页，超出的翻页查看；可预览、下载单条
- **疑似重复输出**：生成后自动做内容指纹比对，列出疑似重复的成片对与重复率（最多 5 对/页翻页），供投放前替换
- **任务历史**：最近 5 条记录（滚动查看），点击可一键载入该任务的参数配置；支持刷新/清空
- **导出投放清单**：把成功成片清单导出 CSV，便于批量上传投放

## 七、工具箱（六大子功能）

左侧导航进入「工具箱」，每个功能独立模块、独立运行，互不影响；**所有工具的输出目录均为必选**（不填无法开始）。

| 工具 | 功能 | 输出 |
|---|---|---|
| **媒体工具** | 转码 / 压缩 / 抽帧 / 音频提取 / 裁剪 / 合并 | `输出目录/转码/` 等按功能自动建子文件夹 |
| **语音识别与索引** | faster-whisper 本地识别视频语音并建立字幕索引（供字幕包装、文本匹配复用） | 本地索引库（`index/`） |
| **字幕包装** | 4 套 ASS 字幕样式，批量文件夹或单文件视频烧录字幕 | `输出目录/` |
| **剪气口** | silero-vad 检测静音，自动删除口播中的气口/停顿 | `输出目录/` |
| **AI 配音** | sherpa-onnx 离线 TTS：女声（huayan）/ 男声（fanchen），可调语速；也可填远程 VoxCPM 服务地址用云端音色 | `输出目录/` |
| **文本匹配拼接** | 输入一段文案，从素材库按"精确字幕匹配优先 + 语义相似兜底"自动挑选口播片段拼接成片，自动烧录文案字幕，输出匹配报告（来源/时间段/匹配度/复用次数） | `输出目录/` |

> 模型全部离线打包在程序内（首次启动不下载）；AI 配音与文本匹配的本地模型约 250MB，已随便携版内置。
> 任务失败明细会写入本地历史（history/），哪个素材、什么错误可直接追溯。

## 八、常见问题

**Q1：背景音乐卡片显示"损坏"图标？**
已修复。现在 BGM 卡片直接显示音乐图标，不再出现缩略图损坏标识，音乐文件本身可正常使用。

**Q2：取消任务后进度为什么不是 100%？**
取消后进度条显示真实已完成数（如 2/200），未完成条数单独显示，不会虚报。

**Q3：生成中修改参数会影响当前任务吗？**
不会。当前任务参数已锁定快照，修改只对下次任务生效。

**Q4：为什么实际生成少于预期生成？**
素材组合不足时，程序按可用组合出片且不重复，实际生成 = 最终结果。

**Q5：如何在多台电脑使用？**
使用便携版压缩包，解压后直接双击 exe，无需安装任何环境（已内置 Python 运行时与 FFmpeg）。

**Q6：怎么更新到新版本？**
程序启动时自动检查 GitHub 新版本（静默，失败不影响使用）。检测到新版且已发布安装包时，左侧栏显示「下载更新」→ 程序内自动下载 → 关闭程序 → 双击程序目录下的《一键替换更新.bat》完成替换重启（会保留你的历史记录和配置）。

## 九、技术说明

- 本地 Web 服务（Python + 浏览器界面），默认端口 8765，被占用时自动切换 8766+ 并打开对应地址
- 视频合成基于 FFmpeg（已内置，支持 NVENC 显卡加速）
- 素材与成片全部本地处理、**不上传任何内容**；仅启动时静默检查 GitHub 新版本（可下载更新包，失败不影响使用）
- 数据存储：任务记录保存在本地 history/、配置模板在 templates/、参数快照在 state/
